# Sistema de Lista de Compras

Projeto desenvolvido em **Python** para praticar lógica de programação e desenvolver um sistema interativo de lista de compras no terminal.

## Funcionalidades

* Adicionar produtos
* Remover produtos
* Listar produtos
* Procurar produtos
* Mostrar quantidade de produtos
* Sair do programa
* Validação e tratamento de entradas do usuário
* Interface colorida utilizando Colorama

## Conceitos praticados

* Variáveis e listas
* Estruturas condicionais
* `for` e `while`
* Funções
* Parâmetros e argumentos
* `match/case`
* `try/except`
* Manipulação de listas
* Utilização de bibliotecas

## Tecnologias

* Python
* Colorama
